# X4 Modding Wiki - предложения и дополнения

[Читать вики](https://x4wiki.com/) · [English](CONTRIBUTING.en.md) · [Создать предложение](https://github.com/dmitriishobolov/x4wiki-Contribute/issues/new/choose)

Здесь принимаются новые статьи, уточнения API, исправления примеров и переводы
для **X4 Modding Wiki**. Не нужно уметь программировать или устанавливать
проект, чтобы предложить изменение.

## Самый простой способ - Issue

1. Откройте [формы предложений](https://github.com/dmitriishobolov/x4wiki-Contribute/issues/new/choose).
2. Выберите новую статью или исправление, на русском либо английском.
3. Укажите ссылку на статью, суть изменения, версию X4, пример и источники.
4. Если пример не запускался в игре, прямо напишите об этом.
5. Нажмите **Create**. Предложение появится в Issues; редактор сможет уточнить
   детали и подготовить материал к публикации.

[Подробная инструкция с примером](CONTRIBUTING.md).

## Если текст уже готов - Pull Request

Сделайте Fork, скопируйте [шаблон статьи](templates/article.ru.md) в
`proposals/ваше-имя-статьи.ru.md`, заполните его и откройте Pull Request.
Есть и [английский шаблон](templates/article.en.md). GitHub позволяет создать
файл прямо в браузере - Git на компьютере не обязателен.

Этот репозиторий принимает предложения. Публикация происходит после проверки
редактором и обновления сайта; создание Issue или слияние PR само по себе
не запускает автоматический деплой. Статусы достоверности нельзя повышать без проверки.

Не присылайте файлы мода, внутренние документы, полные исходники, личные логи,
сейвы и секреты. Нужны публичные первичные ссылки и короткие самостоятельные примеры.

## English

Use [New issue](https://github.com/dmitriishobolov/x4wiki-Contribute/issues/new/choose)
for an article idea, API correction, broken example or translation. Choose an
English form, include the page URL, X4 version, sources and what you actually
tested. You can also submit a Markdown draft under `proposals/` via a pull
request. See the [English contribution guide](CONTRIBUTING.en.md).

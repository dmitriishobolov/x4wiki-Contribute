# Черновики / Drafts

Для новой статьи скопируйте сюда [русский](../templates/article.ru.md) или
[английский](../templates/article.en.md) шаблон под устойчивым именем, например
`ship-hull-example.ru.md`. Для исправления приложите изменённый Markdown
существующей статьи и укажите её исходный URL.

Submit an article draft here using a stable filename such as
`ship-hull-example.en.md`. See [the guide](../CONTRIBUTING.en.md).
